# Dood Cafe — Project Architecture Map
> Generated by QA & Security Audit — Phase 0 Recon

## Tech Stack
| Layer | Technology |
|---|---|
| Backend Runtime | Node.js v22 + Express 5 |
| Database | PostgreSQL (Sequelize ORM v6) |
| Auth | JWT (access + refresh tokens, httpOnly cookie) |
| Frontend | React 18 + Vite |
| Real-time | Socket.io v4 |
| File Upload | Multer (disk + memory storage) |
| Security | Helmet, CORS, HPP, express-rate-limit, express-validator, bcryptjs |
| Deploy Target | Render (backend) / Hostinger (fullstack) |

## API Routes

### Auth /api/v1/auth
POST /register — Public, rate-limited
POST /login — Public, rate-limited, lockout protection
POST /refresh — Cookie-based refresh token rotation
POST /logout — JWT, clears refresh cookie
POST /logout-all — JWT, increments tokenVersion
GET  /me — JWT, returns user profile

### Menu /api/v1/menu
GET / — Public, all items with categories
GET /:id — Public, single item

### Orders /api/v1/orders
POST / — JWT, place order (sensitiveLimiter)
GET /my — JWT, paginated user history
GET /:id — JWT, single order (UUID validated)
PATCH /:id/cancel — JWT, cancel if pending/confirmed

### Admin /api/v1/admin/menu (Admin role required)
GET /categories, GET /items
POST /add-item, POST /add-category, POST /upload-image
PUT /update-item/:id, DELETE /remove-item/:id

### Static
GET /uploads/:filename — Uploaded images
GET /images/** — Menu images from client/src/images
GET /api/v1/health — Health check

## Environment Variables (server)
DATABASE_URL, JWT_ACCESS_SECRET, JWT_REFRESH_SECRET, PORT, NODE_ENV, CLIENT_ORIGIN, JWT_ACCESS_EXPIRES, JWT_REFRESH_EXPIRES

## Security Middleware Stack (ordered)
1. requestIdMiddleware
2. helmet (CSP, HSTS, CORP)
3. cors (origin whitelist)
4. express.json (10MB limit)
5. cookieParser
6. hpp (HTTP Parameter Pollution)
7. sanitizeInputMiddleware (XSS/HTML encoding)
8. morgan (logging)
9. apiLimiter (rate limit /api/*)
10. authLimiter (30 req/15m on /auth/*)
